# portfolio

Portfolio of **Gourav Kumar Bathwal**: live at **https://portfolio-yga8.vercel.app/**

- `source/` is the React + Redux Toolkit + GSAP + Three.js app (see `source/README.md`).
- Vercel builds `source/` on every push (`vercel.json`). The repository root also holds a GitHub Pages build for `/portfolio/`, including a static entry for every project page under `projects/`.
- Editing anything in `source/` and pushing to `main` rebuilds the site automatically (`.github/workflows/build.yml`).
