# portfolio

Portfolio of **Gourav Kumar Bathwal**: live at **https://mr-bathwal.github.io/portfolio/**

- `source/` is the React + Redux Toolkit + GSAP + Three.js app (see `source/README.md`).
- The repository root holds the production build that GitHub Pages serves, including a static entry for every project page under `projects/`.
- Editing anything in `source/` and pushing to `main` rebuilds the site automatically (`.github/workflows/build.yml`).
